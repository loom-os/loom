# Streaming Module

Real-time response streaming for Loom agents.

## Overview

The streaming module provides infrastructure for real-time LLM output and agent communication. It enables clients (CLI, Dashboard) to receive partial responses as they are generated by backend cognitive agents.

## Components

### Types (`types.py`)

Python dataclasses mirroring the protobuf definitions:

| Type                | Description                                     |
| ------------------- | ----------------------------------------------- |
| `StreamChunk`       | Individual content chunk with type and metadata |
| `StreamComplete`    | Completion signal with statistics               |
| `StreamContentType` | Enum: TEXT, THINKING, TOOL_CALL, etc.           |
| `StreamStatus`      | Enum: OK, ERROR, CANCELLED, TIMEOUT             |
| `StreamOptions`     | Request options (timeout, include thinking)     |
| `StreamRequest`     | Request to start a stream                       |
| `StreamStats`       | Execution statistics                            |

### StreamingClient (`client.py`)

Low-level client for receiving streaming responses:

```python
from loom.streaming import StreamingClient

client = StreamingClient(agent_id="my-client")
await client.connect()

async for chunk in client.stream("Explain quantum computing"):
    print(chunk.content, end="", flush=True)

await client.disconnect()
```

### ChatClient (`chat_client.py`)

High-level client with conversation management:

```python
from loom.streaming import ChatClient, StreamContentType

async def on_chunk(content: str, content_type: StreamContentType):
    if content_type == StreamContentType.TEXT:
        print(content, end="", flush=True)
    elif content_type == StreamContentType.THINKING:
        print(f"\n[Thinking] {content}")

async with ChatClient() as client:
    thread_id = client.new_thread()
    response = await client.chat(
        "Explain neural networks",
        thread_id=thread_id,
        on_chunk=on_chunk,
    )
    print(f"\n\nCompleted in {response.stats.duration_ms}ms")
```

### StreamingHandler (`handler.py`)

For backend agents to produce streaming responses:

```python
from loom.streaming import StreamingHandler, StreamContentType

async def on_event(ctx, topic, event):
    if event.type == "stream.request":
        handler = StreamingHandler(ctx, event)

        try:
            # Process with streaming LLM
            async for chunk in cognitive.run_stream(event.payload):
                if isinstance(chunk, str):
                    await handler.send_chunk(chunk)
                elif hasattr(chunk, 'tool_call'):
                    await handler.send_tool_call(
                        chunk.tool_call.name,
                        chunk.tool_call.arguments,
                    )

            await handler.send_complete()
        except Exception as e:
            await handler.send_error(str(e))
```

## Content Types

The streaming protocol supports different content types for rich rendering:

| Type          | Use Case                     |
| ------------- | ---------------------------- |
| `TEXT`        | Main response text           |
| `THINKING`    | Chain-of-thought reasoning   |
| `TOOL_CALL`   | Tool invocation notification |
| `TOOL_RESULT` | Tool execution result        |
| `ERROR`       | Error messages               |
| `STATUS`      | Progress updates             |
| `MARKDOWN`    | Markdown-formatted content   |
| `CODE`        | Code blocks                  |

## Protocol Details

### Event Types

| Event Type        | Direction        | Description     |
| ----------------- | ---------------- | --------------- |
| `stream.request`  | Client → Backend | Start streaming |
| `stream.chunk`    | Backend → Client | Content chunk   |
| `stream.complete` | Backend → Client | Stream finished |
| `stream.cancel`   | Client → Backend | Cancel stream   |
| `stream.state`    | Backend → Client | State update    |

### Envelope Metadata

Streaming information is encoded in envelope metadata:

```python
# Chunk metadata
{
    "stream.sequence": "0",
    "stream.content_type": "0",  # StreamContentType value
    "language": "python",  # Custom metadata
}

# Complete metadata
{
    "stream.status": "0",  # StreamStatus value
    "stream.total_chunks": "42",
    "stream.duration_ms": "1500",
    "stream.tool_calls": "2",
    "stream.first_chunk_latency_ms": "150",
}
```

```python
        await client.chat(message, on_chunk=on_chunk)
```

### Dashboard Integration

```python
# SSE endpoint in dashboard
from loom.streaming import StreamingClient

@app.get("/api/chat/stream")
async def stream_chat(message: str):
    client = StreamingClient()
    await client.connect()

    async def generate():
        async for chunk in client.stream(message):
            yield f"data: {json.dumps({'content': chunk.content})}\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream")
```
